# 도트 아트 개선 기록
2026-10-02

## 적용
- 주인공 두 명: 앞/뒤 스프라이트 4개, 얼굴 중심 초상 2개.
- 레온, 그림자 짐승, 주민 2종: 스프라이트 4개.
- 오두막, 소나무, 참나무, 성당, 우물, 상점: 환경 자산 6개.
- 게임 및 타이틀에 실제 로드. 성당 충돌 영역 조정. 길의 이끼와 돌 틈, 풀 디테일 보강.
- 움직임은 앞/뒤 방향 전환, 이동 바운스, 공격 기울기. 전용 다프레임 걷기·공격 시트는 아직 아님.

## 사용 기술과 검증 근거
[Sharp 공식 GitHub](https://github.com/lovell/sharp)와 [공식 릴리스](https://github.com/lovell/sharp/releases), [공식 API](https://sharp.pixelplumbing.com/api-resize/)를 확인. 공식 저장소에 테스트/CI와 2,500개 이상 커밋 및 약 3.27만 별이 표시됨(조사 당시). 이 수치는 무결함 보증이 아니며, 실제 설치/가공/출력 확인을 함께 실시했다.

sharp 0.35.5를 개발 의존성으로 정확히 고정하고 package-lock.json 포함. Apache-2.0 라이선스 사본을 자산 폴더에 보관. libvips 기반 자르기, 알파 처리, nearest-neighbor 리사이즈, 팔레트 PNG 출력에 실제 사용. 최초 설치 시 npm audit: 취약점 0개 보고(해당 시점).

원본은 내장 이미지 생성 도구로 만들고 Sharp로 게임용 48~192px PNG를 제작했다. 손으로 모든 픽셀을 그렸다고 주장하지 않는다. 상업 게임 자산을 추출하지 않았다. 참고: [프리렌 공식 캐릭터 페이지](https://frieren-anime.jp/character/)의 판타지 의상/명확한 실루엣을 디자인 분석 자료로 확인; 특정 캐릭터 복제나 동일 의상 재현은 목표로 하지 않았다.

## 원본 프롬프트 요약 / 재현
1. 투명 2×2 시트: 독자적인 은발 성기사와 청록 망토 방랑자의 앞/뒤, 세부 갑옷과 천 소재, JRPG 도트 표현.
2. 투명 3×2 시트: 목조 주택/소나무/참나무/종탑 성당/우물/상점, 일관된 청록·청색 슬레이트·따뜻한 금색 팔레트.
3. 투명 2×2 시트: 가시가 자란 수호기사, 보라색 그림자 짐승, 약초상과 노인.

원본: public/assets/art-v2/source/.
실제 출력: public/assets/art-v2/.
정확한 영역과 치수: manifest.json 및 tools/build-art.mjs.
재생성: npm ci 후 npm run art:build. 원본 PNG는 새로 생성하지 않고 저장된 이미지를 재가공한다.
