# 새벽의 서약 — 프롤로그 설계

2026-09-30. 사용자 승인: 《새벽의 서약》 2인 온라인 협동 모바일 도트 RPG 프롤로그. 추가 요구: 다른 서브컬처/RPG의 공식 레퍼런스를 조사하고 UI/폰트/UX에 반영. 사용자의 '좋아 시작해줘'를 구현 진행 승인으로 적용.

## 플레이와 이야기
에델 마을의 꺼진 종 → 세리아와 만남 → 주민 3명 구출 → 두 봉인석 동시 활성화 → 타락한 수호기사 → 종을 울린 후 왕가의 문장 발견. 대화는 양 플레이어가 읽고 준비했을 때 진행한다. 혼자 시작하면 세리아 AI가 전투와 봉인석을 돕는다. 실제 협동은 방 코드로 두 브라우저가 같은 서버에 접속한다.

## 첫 사용 경험
타이틀에는 프롤로그 시작, 친구와 협동 두 진입점. 가입/수집/상점 없음. 세로 모바일은 엄지 이동 패드와 공격/스킬/회피, 가까운 목표와 상호작용 버튼. PC는 WASD/방향키와 J/K/Space/E. 화면에 현재 행동만 표시한다. 대화 중 전투 정지. 상태는 색과 문자를 함께 사용. 실패하면 현재 전투부터 재도전. 소리 기본 꺼짐, 선택시 합성 효과음. 동작 줄이기 옵션. 대화 기록 제공.

## 아트와 타이포그래피
직접 그린 Canvas 도트 배경/캐릭터/초상. 청록 밤, 은빛 머리, 낡은 금색, 촛불 주황. 글자는 도트가 아닌 선명한 실제 텍스트. Noto Serif KR 제목, Pretendard 본문. 라이선스를 폰트와 함께 보관. 캐릭터와 배경을 제3자 게임에서 추출하지 않는다.

## 구조
Node 내장 HTTP 서버 + SSE 상태 스트림 + POST 입력. 서버가 30Hz로 이동/피해/단계/AI를 계산하고 15Hz로 상태 전송. 프런트는 Canvas 렌더링과 DOM UI. 외부 런타임 의존성 없음. 입력 제한/방 토큰/2명 제한/유휴 방 정리. 같은 네트워크 접속 가능; 공개 인터넷 호스팅/HTTPS는 배포 단계가 별도로 필요하다. 공개 배포 완료라고 오인시키지 않는다.

## 검증
실제 게임 규칙 단위 테스트: 이동 제한, 공격 쿨다운, 부활, 퍼즐, 대화, 보스, 재도전. 두 HTTP 클라이언트 연결 테스트: 같은 상태, 다른 방 격리, 초과 입장, 잘못된 토큰. 브라우저로 타이틀→플레이 및 모바일 화면/버튼/오버플로 확인. 실제 휴대폰이나 외부 인터넷 플레이 미검증은 명시.
